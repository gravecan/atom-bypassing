## How to Delete Files

SSH into VPS first, then:

### Delete Single File
```bash
rm /home/ubuntu/files/filename.dll
```

### Delete Multiple Files
```bash
rm /home/ubuntu/files/file1.dll /home/ubuntu/files/file2.exe
```

### Delete All Files in Folder
```bash
rm /home/ubuntu/files/*
```

### Delete Entire Folder
```bash
rm -rf /home/ubuntu/files/foldername
```

### Delete Files by Pattern (e.g., all .dll files)
```bash
rm /home/ubuntu/files/*.dll
```

## How to Start Cloudflare Tunnel (Free URL)

SSH into VPS, then run:
```bash
cloudflared tunnel --url http://localhost:80
```

It will print a URL like:
```
https://something-random-words.trycloudflare.com
```

**That's your download link!** Anyone can access files at:
```
https://something-random-words.trycloudflare.com/atomic.dll
```

**IMPORTANT:** Keep that terminal open — closing it kills the tunnel.

## File Server Status

### Check if File Server is Running
```bash
sudo systemctl status fileserver
```

Should show `active (running)` in green.

### Restart File Server
```bash
sudo systemctl restart fileserver
```

### Stop File Server
```bash
sudo systemctl stop fileserver
```

### Start File Server
```bash
sudo systemctl start fileserver
```

## Troubleshooting

**"Permission denied" when uploading:**
- Make sure the path `/home/ubuntu/files/` exists on VPS
- Check with: `ls /home/ubuntu/files/`

**"Connection refused":**
- Check file server is running: `sudo systemctl status fileserver`
- Restart it: `sudo systemctl restart fileserver`

**Tunnel URL not working:**
- Make sure you kept the tunnel terminal open
- Restart the tunnel: `cloudflared tunnel --url http://localhost:80`

**Can't delete files:**
- Make sure you're SSH'd into the VPS first
- Check file exists: `ls /home/ubuntu/files/`
